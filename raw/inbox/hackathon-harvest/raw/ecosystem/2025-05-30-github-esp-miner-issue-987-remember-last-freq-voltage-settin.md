When the Bitaxe overheats, it goes into overheat mode and the frequency and voltage reset . Could we add a feature to have it remember and display the previous settings that led to the overheat even while it lowers the actual settings? This way we don't have to remember or write down the previous settings elsewhere? This'd be very helpful when overclocking or when ambient temps go up in general to know what settings to try next if we want to slightly tick down the hashrate and run cooler.</div>
