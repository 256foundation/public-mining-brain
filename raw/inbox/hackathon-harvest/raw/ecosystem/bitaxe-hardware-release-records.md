### Release notes

This is the first release of the bitaxeGamma.

- Based on the bitaxeSupra 402 HW but with the BM1370
  - Voltage regulator is now the TPS546 with integrated switches
  - Removed the INA260 power meter
  - Removed the DS4432U+ current DAC (was used to adjust the old voltage regulator)
