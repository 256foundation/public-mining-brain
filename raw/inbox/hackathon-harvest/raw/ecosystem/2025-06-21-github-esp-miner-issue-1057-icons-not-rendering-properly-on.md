## Description

Icons such as the ones that appear to the left of the Menu options are not rendering properly on Chromium- or Firefox-based browsers.

**To Reproduce**
Steps to reproduce the behavior:
1. Go to 'Dashboard'
2. Notice that the icons that should appear to the left of the text description for the options under Menu are not rendering (Chromium-based browsers) or appear as a small square with "E9" on top and a what appears to be a 2-digit hex number on the bottom (Firefox-based browsers)

**Expected behavior**
Icons such as the "Swarm", "Network", "Customization" or the sort icon in the Swarm page should render like in prior versions.
