## Description

Settings - Stratum Password

Some pools allow the user to enter options here (Zergpool) with how you can mine on the pool (solo or pooled) and the coin(s) to mine etc.

When entering text in this field have it so that the user can see what is being entered into this field instead of masking each character with a '*' so that it can be checked for any typo errors before it is saved via the "Save" button.

![stratumpassword](https://github.com/user-attachments/assets/407f75b8-6e98-4d5b-b436-642cef3f8418)

The content of this field would then be hidden when the "Save" button is clicked on followed by "Restart" to update the pool of these changes for the device.
