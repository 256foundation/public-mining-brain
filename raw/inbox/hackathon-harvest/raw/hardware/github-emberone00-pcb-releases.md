## emberOne/00 v3 (v3-release)

- Published: 2025-04-30
- Link: https://github.com/256foundation/emberone00-pcb/releases/tag/v3-release
- Prerelease: False

The first official release of the emberOne/00!

- Design is confirmed working with actual hardware. 12-24VIN @ 100W
- [Pyminer test firmware](https://github.com/skot/emberone-miner/tree/emberone-BM1362-support) was used. 2 TH/s @ 500MHz hash frequency and 3.4V. More is definitely possible with tuning.
- [emberone-usbserial-fw](https://github.com/256-Foundation/emberone-usbserial-fw) loaded.
- Make sure to supply adequate cooling for the ASICs as well as the 4 power mosfets (Q1, Q2, Q3, Q4)
