## Overview

Public Pool is a fully open-source, solo Bitcoin mining pool. You can point miners at the official instance or host the pool yourself. It is one of the projects documented on the OSMU wiki, and it is the default pool for the Nerdminer.

## What it is

Public Pool was written from scratch. The stated goals are easy installation, a modern interface, maintainability and low complexity. The repository holds both the stratum server and the GUI, and contributions are welcome.

## The official instance

The official instance is at web.public-pool.io and is managed by Ben. The backend runs on hardware under his physical control. Only the GUI relies on cloud infrastructure.

## Who uses it

The Nerdminer works with Public Pool by default, and the pool supports Nerdminers. The setting can be changed. See [The Nerd Miner Family](nerd-miner-family.md).
