## 5 signal lines

1. **SECPOOL identity/who runs it: not disclosed on site.** No company name anywhere in the static shell or the 1.3 MB app bundle (agreement says only "本公司"); their own Zendesk help center is closed, leaving help@secpool.com and in-app chat as the only support surfaces. First-party disclosures (from their own bundle): multi-mode FPPS/PPS/PPLNS (+PPS+ homepage metrics), daily settlement, "0 Fee" promo string, KYC machinery (`SECPOOL_KYC_CRYPTOKEY`), custodial sub-account model.
2. **Braiins fee history/structure: 2.5% FPPS pool fee, 0% if you mine with Braiins OS firmware** (the 0% tie-in is restated in their SV2 manual via the legacy slushpool endpoint note). Full published table: min payout 0.0002 BTC, free on-chain payout ≥0.005 BTC, free Lightning payouts (1 sat–0.005 BTC), daily payouts 09:00 UTC. "World's longest running mining pool" (since 2010, ex-Slush Pool; 1,294,383 BTC all-time on-page). Non-KYC claimed on the pool homepage.
3. **Luxor payout scheme: FPPS with a published formula** (144-block fee lookback, p5–p95 trimmed, per-block-height rate) and self-described "discount to spot FPPS" as the fee — **no numeric % published**. Daily/weekly/monthly payouts after 04:00 UTC; BTC min threshold 0.001 + 0.000075 withdrawal fee; US-based, SOC 2 Type 2-certified, institutional client base (Soluna, Genesis, TeraWulf cited). Cloudflare blocks plain curl on docs.luxor.tech (agent-friendly `/llms.txt`/`.md` exist).
4. **SpiderPool garble status: site unusable to raw-HTTP capture** (empty Next.js shell; `__NEXT_DATA__` pageProps empty) — browser render required; park this note for any future raw-only pipeline. Once rendered it's the most transparent of the set: fee printed on the homepage as **PPLNS 1% / FPPS 4%** (miner's choice), BTC threshold 0.005, payment window 02:00–10:00 UTC daily, 80.88 EH/s, ~191k miners, merged DMT-NAT/FB rewards, LN/on-chain, System Status Monitor linked; no KYC/custody/SV2 statements; operator unnamed.
5. **MARA Pool: the pool's own web presence is dead** — marapool.com serves a TLS handshake failure on 443 and 301-redirects HTTP to the corporate home, which no longer lists the pool anywhere (sitemap check). First-party record survives in ir.mara.com PRs: "only self-owned and operated mining pool among public miners… no fees to external operators" (Apr 2025), opened to external North American miners in 2021 with third-party US audit and NYDIG member services.
