## Description

We need to make axeos a bit more adjustable and have a minimilized presentation of information.
In order to stay in line with "grannyproof" we need to reduce the information we display.

The current design is phenomenal but lacks in grasp on first sight. Users will be overloaded with information they either don't need or don't understand.
With tools like a draggable and resizeable dashboard we can make AxeOS less busy for the user.
