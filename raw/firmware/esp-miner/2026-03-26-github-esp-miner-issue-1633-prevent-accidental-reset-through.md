## Description


On a number of occasions I've accidentally reset the device through the AXE-OS page, the control panel icon is placed quite close to the reset button and when using a tablet to access the web interface it is too easy to accidentally hit the reset icon which takes place immediately and without confirmation.

I propose that the reset icon include a pop-up to confirm the reset procedure to avoid inadvertent resets of the device.
