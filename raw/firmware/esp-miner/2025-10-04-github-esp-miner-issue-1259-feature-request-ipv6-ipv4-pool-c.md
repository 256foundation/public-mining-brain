## Description

With the new option to use an IPv6 connection to the pool, this should be indicated in the dashboard. It could be indicated after the pool name as “(IPv6)” or “(IPv4)”. 

For example, CK-Pool offers both types of access under the general address (solo.ckpool.org). So if you don't use the dedicated accesses (solo4 or solo6), it is not possible to identify which access is being used. 

Addendum:
When logging in to eusolo.ckpool.org, an IPv6 connection is not established, as stated on CK-Pool. It remains an IPv4 connection.
However, I cannot verify which site is at fault here.
IPv6 works on eusolo6.ckpool.org.
