## Description

Currently the Bitaxe switches between 2 screens with particular information on them. I find some of the stats helpful, and some of them no longer useful once it is configured. It would be nice to have a way to select the options that would be shown on the screen in a check list.

Due to space considerations the user could pick so many items per screen, specify which screen they would be included on, and how many different screens would be shown. 

For example if a user wanted a lot of information they could specify 3 screens of data, including more information with the new suggestions below, or others if more are considered.

Some other options that would be nice to offer on the screens that are not currently available:
1) The wallet address for the mining reward
2) The Voltage Regulator temperature (higher priority)
3) The long term average hashrate over a period of time

For my personal usage I would like to be able to setup a single screen showing Hashrate, energy usage per TH, Asic temp and Voltage Regulator Temperature, and skip showing the current IP information and SSID info.

In the case a user has issues connecting and cannot remember the SSID or the IP of the unit, we could have a way to show these by pressing one of the two buttons quickly (or holding) on the front to show this information, but for the most part the IP and SSID are not needed once configured, and scrolling to these screens is not helpful.
