# Key Features

> 

- **Overclocking and Undervolting:** The firmware allows increasing chip clock frequency to boost Hashrate beyond factory specifications, or reducing frequency and voltage to decrease power consumption and improve efficiency (W/TH/s).
- **Overclocking Profiles:** Flexible management of power-to-performance ratio.
- **Auto-tune:** The algorithm automatically selects the optimal frequency and voltage for each chip individually, ensuring maximum performance and stability within the selected profile.
- **Automatic Profile Switching:** The firmware automatically switches between Preset profiles based on current operating conditions, selecting the most optimal operating mode.
- **Power Management:** In case of Pool connection loss, the device automatically maintains power or shuts down. The mining pause function temporarily reduces load and fan speed to minimize power consumption.
- **Centralized Management:** Integration with HashCore Toolkit for managing large fleets of miners.
- **Cooling Management:** Configurable fan control algorithms with defined temperature thresholds. For immersion cooling setups, a mode for complete fan shutdown without additional hardware is provided.
- **API:** Secure device management via API requests for integration with external monitoring and automation systems.
