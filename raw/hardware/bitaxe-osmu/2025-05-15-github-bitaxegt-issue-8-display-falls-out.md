## Description

The display falls out so easily. As much as I am loathe to add any kind of build requirement, it needs something. A paperclip would be better than losing a whole display in a box that was accidentally thrown out.

## Comments

### skot on 2025-05-15

I hear ya. The current display connector is very far from ideal. The main issue right now is that we don't have any control over the design of the display module/pcb/connector. We could easily make our own, but that will raise prices and reduce availability. 

I think longer term the solution is to use the bare OLED directly on the Bitaxe. This will increase the price, complexity and decrease availability, but hopefully not tooo much.
